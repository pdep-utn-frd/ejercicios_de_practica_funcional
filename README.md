# Ejercicios de repaso: programación funcional (2026)

Ejercicios cortos, un archivo por tema para repasar los temas vistos del paradigma Funcional.

1. Leé el `.md` del tema: tiene un repaso rápido y los enunciados con ejemplos de salida.
2. Abrí el archivo `.hs` que corresponda y reemplazá los `undefined` (o descomentá los bloques, en los temas donde definís tipos).
3. Ejecuta en GHCi:

   ```
   ghci OrdenSuperior.hs
   ghci> aplicarDosVeces (+ 1) 5
   ghci> :r            -- recarga después de editar
   ```
